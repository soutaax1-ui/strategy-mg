# 戦略 MG Figma Make プロンプト集

**使い方**: Figma Make を開いて、以下の各プロンプトをコピペして 1 画面ずつ生成する。

**推奨順序**: タイトル → ダッシュボード → カード行動選択 → 親子入札 → 期末決算 → 6都市市場 → 最終結果

**注意**: プロンプトは日本語ベースだが、デザイン用語 (色コード・フォント名・スペーシング) は英語のままにしてある。Figma Make が正確に認識するため。

---

## 共通: デザインシステム指定 (全プロンプト共通部分)

各プロンプトの冒頭にこのブロックを必ず含める。

```
【デザイン方向性】
- レトロ 8 ビット × クラッシュロイヤル風のゲーム UI
- ダーク背景 + ビビッドな差し色
- ハードシャドウ (blur: 0px の角ばった影)
- 角丸は基本 0px (鋭角)
- ピクセルアート風のアイコン

【カラーパレット】
- Background base: #0f0e1a
- Background surface: #1a1830
- Background elevated: #2a2747
- Border: #3d3a5e
- Accent gold (primary CTA): #ffba08
- Accent cyan (player highlight): #00d9ff
- Accent pink (risk/danger): #ff4d8d
- Accent lime (positive): #80ed99
- Text primary: #f1f0ff
- Text secondary: #a8a3c7
- Success green: #06d6a0
- Danger red: #ff3366

【4社識別カラー】
- あなたの会社: cyan (#00d9ff)
- アルファ商事: pink (#ff4d8d)
- ベータ工業: gold (#ffba08)
- ガンマ商会: lime (#80ed99)

【タイポグラフィ】
- 大見出し: "Press Start 2P" 32px (英数字のみ)
- 和文見出し: "DotGothic16" 24px (Google Fonts のピクセル和文)
- 本文 (和文): "Noto Sans JP" Regular/Bold 14-16px
- 数値: "JetBrains Mono" Bold 14-28px (タブラー数字)

【コンポーネントスタイル】
- ボタン: 角丸 0px, padding 12px 24px, ハードシャドウ "4px 4px 0px #000"
- カード: 背景 surface, 2px border, ハードシャドウ "2px 2px 0px #000"
- 入力欄: 背景 base, 2px border, フォーカス時 cyan
- ホバー: シャドウ強化 + わずかに浮き上がる
```

## 使い方の補足

### Figma Make の起動方法
1. Figma にログイン
2. 新規ファイル作成 → 左上メニューから「Make Design」(または右パネルの AI アイコン)
3. プロンプト入力欄に上記のプロンプトを貼る
4. 生成ボタン (数十秒〜数分待つ)
5. 出てきたデザインを調整 (Figma Make は AI 提案を元に手動で微調整できる)

### 1 つずつ生成する理由
- 1 プロンプトに 7 画面分を詰め込むと品質が落ちる
- 1 画面ずつ作って気に入らなければ再生成
- デザインシステム部分が一貫していれば、画面間の統一感は保てる

### 順番の推奨
1. **タイトル画面**: ゲームの世界観を確立、デザイントーンを確認
2. **ダッシュボード**: 一番複雑、ここが決まれば他の画面が楽
3. **カード行動選択**: ゲームプレイ中の主要画面
4. **親子入札**: ゲームの華
5. **期末決算**: 学習価値の核
6. **6都市市場**: 任意、後回し可
7. **最終結果**: ゲームの締めくくり

### Figma Make で出てきたデザインを Claude Code に渡す方法
1. Figma で各画面のスクショを撮る (Cmd + Shift + 4 で範囲指定)
2. Claude Code に「このスクショのデザインに合わせて index.html を更新して」と依頼
3. スクショを添付 (Claude Code は画像を読み取れる)

これで Figma → Claude Code の橋渡しが完了する。

### トラブル時の対処
- Figma Make が想定と違うデザインを出した: プロンプトの「雰囲気」セクションを強化、参考画像を添付
- 文字が読めないデザインになった: 「コントラスト強めに」「テキストサイズを XXpx に」と具体的に指示
- レイアウトが崩れる: 画面を縦に分割した構造を箇条書きで明示する
